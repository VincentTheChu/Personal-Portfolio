# Vincent Chu Portfolio

Personal portfolio website for Vincent Chu, Software Engineer (C# / .NET).

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Static export enabled for Vercel or static hosting

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
```

The site is configured with `output: "export"`, so production files are emitted to `out/` for static hosting.
